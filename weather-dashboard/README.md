# Weather Dashboard

## 🌡️ Modern Desktop Weather Application

Полнофункциональное приложение для отслеживания погоды в реальном времени с поддержкой прогнозов на 5 дней.

## 🎯 Основные возможности

### 📊 Текущая погода
- Температура и "ощущаемая" температура
- Минимальная и максимальная температура дня
- Влажность и давление
- Скорость ветра
- Видимость
- Описание погодных условий с эмодзи иконками

### 📅 Прогноз на 5 дней
- День и дата
- Температура днём
- Диапазон температур
- Влажность
- Скорость ветра
- Описание погодных условий

### 💾 Функции приложения
- Сохранение последних 10 города в памяти
- Быстрый выбор из сохранённых городов
- Индикатор загрузки данных
- Обработка ошибок сети
- Темная и светлая тема
- Отзывчивый дизайн

## 🛠️ Технические характеристики

### Используемые технологии
- **Язык:** C++ (C++17)
- **Фреймворк:** Qt 6 (Widgets, Network)
- **API:** OpenWeatherMap (https://openweathermap.org/api)
- **Протокол:** HTTP/REST с JSON

### API Интеграция
- Получение текущей погоды: `/weather` endpoint
- Получение прогноза: `/forecast` endpoint
- Параметры запроса: город, API ключ, единицы измерения (метрические)

## 📋 Требования

- Qt 6.0 или выше
- C++17 совместимый компилятор
- CMake 3.16 или выше
- Интернет соединение
- API ключ от OpenWeatherMap (бесплатный)

## 🚀 Установка и запуск

### Получение API ключа

1. Перейдите на https://openweathermap.org/api
2. Создайте аккаунт (бесплатно)
3. Получите API ключ в разделе API keys
4. Вставьте ключ в код (WeatherDashboard.cpp, строка ~52)

### Сборка проекта

```bash
cd weather-dashboard
mkdir build
cd build
cmake ..
make
./WeatherDashboard
```

### Использование Qt Creator

1. Откройте `CMakeLists.txt` в Qt Creator
2. Выберите необходимый kit
3. Нажмите Build → Build All (Ctrl+Shift+B)
4. Запустите приложение (Ctrl+R)

## 📖 Использование

1. **Поиск города:**
   - Введите название города в поле "Enter city name"
   - Нажмите "Search" или Enter

2. **Выбор сохранённого города:**
   - Выберите город из выпадающего списка "Saved"
   - Приложение автоматически загрузит погоду

3. **Переключение темы:**
   - Нажмите кнопку "🌙 Dark" / "☀️ Light"
   - Тема изменится в реальном времени

## 📝 Классы

### WeatherAPI
Управление сетевыми запросами к OpenWeatherMap API:
- `fetchCurrentWeather()` - получение текущей погоды
- `fetchForecast()` - получение прогноза
- Парсинг JSON ответов
- Обработка ошибок сети

### WeatherData
Структура для хранения данных текущей погоды:
- Температура, влажность, давление
- Скорость ветра, облачность
- Описание, иконка

### ForecastData
Структура для хранения данных прогноза:
- Дата, температура
- Влажность, давление, ветер
- Вероятность осадков

### WeatherDashboard
Главное окно приложения:
- Управление UI
- Обработка пользовательского ввода
- Отображение данных
- Управление темами

## 🐛 Известные ограничения

1. Требуется активное интернет соединение
2. Прогноз ограничен 5 днями
3. API ключ вставляется в код (рекомендуется хранить в конфиге)
4. Некоторые города могут иметь точное совпадение по названию
