# PRIM

## Децентрализованное P2P-общение

Десктопный Peer-to-Peer (P2P) мессенджер для локальных сетей (LAN), построенный на принципах децентрализации и антистрессового дизайна. Приложение автоматически обнаруживает собеседников в сети, шифрует пароли на клиенте и обеспечивает прямой обмен сообщениями, фотографиями и голосовыми записями без использования сторонних серверов.

## 🎮 Особенности

### Полная децентрализация (P2P)
Прямая передача данных между клиентами по протоколу TCP, минуя промежуточные серверы

### Автоматическое обнаружение (UDP Discovery)
Клиенты самостоятельно находят друг друга в Wi-Fi или Ethernet сети

### Групповые чаты
Создание групп с отправкой сообщений всем участникам

### Запись и воспроизведение аудио
Интегрированная запись голосовых сообщений и удобный плеер с визуальным статусом проигрывания

### Безопасная локальная БД
Хранение истории чатов и профилей на компьютере в SQLite с хэшированием паролей по стандарту SHA-256

### Система динамических тем
Мгновенное переключение между классическим темно-синим дизайном и теплой светлой темой

### Умный интерфейс
Автоматическая прокрутка переписки вниз при отправке/получении сообщений и адаптивный размер пузырей чата

## 🕹️ Управление и интерфейс

| Элемент управления | Действие |
|---|---|
| **Добавить** | Добавление нового собеседника в список контактов по его номеру телефона |
| **Группа+** | Создание группового чата (ввод участников через запятую) |
| **Изменить** | Переименование выбранного контакта в списке чатов |
| **Удалить** | Удаление личного чата или выход из группы с полной очисткой локальной истории |
| **Тема ☀️ / 🌙** | Переключение между светлой и темной темами оформления в реальном времени |
| **Поле ввода** | Набор текстового сообщения |
| **Enter / Отправить** | Мгновенная отправка набранного текста собеседникам |
| **Фото** | Выбор и отправка графического файла (PNG, JPG, BMP, GIF) |
| **Голос** | Первое нажатие запускает запись звука / Второе нажатие останавливает запись и отправляет её |

## 💬 Режимы общения

### Личный диалог (1-на-1)
- Прямое TCP-подключение к IP-адресу собеседника
- Автоматическое обновление адреса пира при его перемещении внутри локальной сети

### Групповой чат
- Рассылка системного пакета всем участникам для синхронного создания группы на их устройствах
- Поочередная отправка каждого сообщения всем членам группы через быстрые сессии TCP
- Отображение имени автора над входящим текстовым сообщением

## 🎨 Оформление (Темы)

### Тема 🌙 — Классическая темная
- **Фон окна:** Глубокий темно-синий (#0e1621)
- **Сайдбар:** Сине-серый (#17212b)
- **Пузыри:** Синий (#2b5278) для исходящих и темно-серый (#182533) для входящих

### Тема ☀️ — Светлая «Prim Shell»
- **Фон окна:** Теплый оттенок скорлупы яйца (#f9f8f6)
- **Сайдбар:** Чистый белый (#ffffff)
- **Пузыри:** Нежно-голубой (#e1f3fc) для исходящих и белый (#ffffff) для входящих
- **Акцент:** Шалфейно-зеленый «Fresh Leaf» (#7c9a7b) для выделения элементов и имен

## 🛠️ Технологии

- **Язык программирования:** C++ (C++17)
- **Фреймворк:** Qt 6 (Widgets, Network, Sql, Multimedia)
- **СУБД:** SQLite 3
- **Тип приложения:** Десктопный графический мессенджер (GUI)

## 📋 Требования

- Qt 6.0 или выше
- C++17 совместимый компилятор
- SQLite 3
- CMake 3.16 или выше

Использование Qt Creator (qmake)

  1)Откройте файл Prim.pro в Qt Creator (через меню Файл → Открыть файл или проект...).

  2)Выберите нужный комплект сборки (Kit), например MSVC, и нажмите кнопку Настроить проект (Configure Project).

  3)Запустите приложение с помощью сочетания клавиш Ctrl + R (или нажмите на зеленый треугольник в левом нижнем углу). Qt Creator сам автоматически запустит qmake, скомпилирует файлы    и откроет мессенджер.
